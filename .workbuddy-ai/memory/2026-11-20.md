## 修复 Husky pre-commit 在 IDE 提交时失败（code 127）

- 现象：提交弹窗报 `/usr/bin/env: 'bash': No such file or directory` + `husky - pre-commit script failed (code 127)`。
- 根因：`.husky/pre-commit` 原为 `npx lint-staged`；Windows 全局 `npx`（`C:\Program Files\nodejs\npx`）是 `#!/usr/bin/env bash` 脚本。IDE 提交进程的 PATH 中缺少 Git Bash 的 `usr/bin`，导致 env 找不到 bash。
- 修复：将 `.husky/pre-commit` 改为直接调用本地 `./node_modules/.bin/lint-staged`（该文件是 `#!/bin/sh`，不依赖 bash/npx）。
- 验证：分别用精简 PATH（模拟 IDE 环境）和正常环境执行 `.husky/_/pre-commit`，均 exit 0（提示无匹配暂存文件）。
- 注意：本机 Git Bash 在 `C:\Program Files\Git\{bin,usr/bin}\bash.exe`；若其他 hook 仍用 npx 也会有同类问题。
